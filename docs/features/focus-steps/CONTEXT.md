# Domain Context — focus-steps

## Glossary

- Goal — a name that groups finished stairs and the total of their time. It appears when the Owner names it while opening a stair, and only if that stair actually opens. The same name means the same characters after spaces at the ends are ignored. Capital letters and small letters are different characters. That name joins the existing goal. A name made only of spaces is empty. NOT a finish line (there is no stage or numeric target) and NOT a stair.
- Owner — the only person who opens stairs and reads progress on their own goals. NOT another person and NOT an account.
- Stair — one named smallest completed action under one goal. Its time runs while it is open and the Owner can see the app, until it is marked done. Closing the last view, a crash, or a power loss means the app is not open, and that time is not included. Several views count the time once. NOT a configured work interval and NOT a goal.
