# Domain Context — focus-steps

## Glossary

- Goal — a name that groups finished stairs and the total of their time. It appears when the Owner names it while opening a stair. The same name joins the existing goal. NOT a finish line (there is no stage or numeric target) and NOT a stair.
- Owner — the only person who opens stairs and reads progress on their own goals. NOT another person and NOT an account.
- Stair — one named smallest completed action under one goal. Its time runs while it is open and the app is open, until it is marked done. Time while the app is closed is not included. NOT a configured work interval and NOT a goal.
